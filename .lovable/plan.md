# ส่งสลิปจ่ายคู่ค้าเข้าไลน์ แล้วมาผูกกับบิลที่วางไว้ทีหลัง

## ตอบคำถามสั้นๆ

ทำได้ค่ะ แต่ตอนนี้ยังผูกได้เฉพาะกรณีที่ใส่รหัสบิล `@B####` ในบันทึกช่วยจำของสลิปตอนโอน
ถ้าลืมใส่รหัส สลิปจะกลายเป็นรายการค่าใช้จ่ายเดี่ยวๆ และบิลจะยังค้างอยู่ในรอจ่าย โดยยังไม่มีปุ่มให้จับคู่ทีหลังด้วยมือ

## สิ่งที่จะเพิ่ม

1. ปุ่ม "ผูกสลิปที่ส่งเข้าไลน์แล้ว" ในทุกบิลคู่ค้าที่รอจ่าย (และในใบสั่งจ่าย P####)
2. หน้าต่างเลือกสลิป
   - แสดงสลิปที่เข้ามาช่วง 60 วันล่าสุดและยังไม่ถูกผูกกับบิลใด
   - เรียงลำดับให้ใบที่ยอดใกล้ "ยอดโอนจริง" หรือ "ยอดรวม" ของบิลขึ้นก่อน พร้อมป้ายบอกว่าตรงยอดไหน
   - เห็นรูปสลิป วันที่ ยอด ชื่อผู้รับ และค้นหาด้วยยอด/ชื่อ/วันที่ได้
   - ไม่จับคู่อัตโนมัติ ต้องกดเลือกเอง เพื่อไม่ให้ผูกผิดใบ
3. เมื่อกดผูก ระบบจะ
   - ตั้งบิลเป็นจ่ายแล้ว ใส่วันที่จ่ายจากวันบนสลิป
   - ใช้ไฟล์สลิปเดิมเป็นหลักฐานการจ่ายของบิล (ไม่อัปโหลดซ้ำ ไม่สร้างรายการค่าใช้จ่ายใหม่)
   - ผูกรายการค่าใช้จ่ายเดิมเข้ากับบิล และเติมข้อมูลที่บิลมีให้รายการนั้น (คู่ค้า/รายละเอียด/ภาษีหัก ณ ที่จ่าย) ถ้ารายการยังว่าง
   - ถ้าบิลอยู่ในใบสั่งจ่ายชุดเดียวกัน จะปิดทุกใบในชุดพร้อมกัน
4. ปุ่ม "ยกเลิกการผูก" สำหรับกรณีผูกผิด กลับไปเป็นบิลรอจ่ายและรายการค่าใช้จ่ายเดี่ยวเหมือนเดิม
5. ข้อความแนะนำในหน้าเตรียมจ่ายปรับใหม่: ส่งสลิปเข้าไลน์ได้เลย ใส่ `@B####` จะตัดจ่ายอัตโนมัติ ถ้าลืมใส่ก็มาผูกทีหลังได้จากปุ่มนี้

## รายละเอียดทางเทคนิค

- UI ใหม่: `src/components/payment/LinkSlipToBillSheet.tsx` เรียกจาก `src/pages/PaymentQueue.tsx` (แถบบิลคู่ค้า และแถบใบสั่งจ่าย)
- คิวรีสลิป: `expenses` ที่ `receipt_url is not null` และ id ยังไม่ปรากฏใน `vendor_invoices.matched_expense_id` ช่วง 60 วัน
- ตอนผูก: อัปเดต `vendor_invoices` (`status='paid'`, `paid_at`, `payment_slip_url` = receipt_url ของรายการ, `matched_expense_id`) และปิดทุกใบใน `voucher_id` เดียวกัน รวม `staff_invoices` ในชุดเดียวกัน
- ยกเลิกการผูก: คืนค่า `status='approved'`, ล้าง `paid_at`/`payment_slip_url`/`matched_expense_id` โดยไม่ลบรายการค่าใช้จ่าย
- ไม่แตะทริกเกอร์วันที่/ประวัติการลบ ไม่เรียก FlowAccount API ไม่เปลี่ยนตรรกะกันสลิปซ้ำเดิมของไลน์
